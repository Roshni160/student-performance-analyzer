### Student Performance Analyzer & Grade Predictor

This project analyzes student academic data to:
- Predict final grade (`G3`) using regression
- Predict pass/fail using classification

I have used data from the [UCI Student Performance Dataset](https://archive.ics.uci.edu/ml/datasets/student+performance) and explored how demographics, study habits, and family background influence grades.

### Files
- `notebook/student_performance.ipynb` – Jupyter notebook
- `data/student-mat.csv` – Dataset
- `student_performance_report.pdf` – Exported PDF report
- `requirements.txt` – Libraries used

### Models Used
- RandomForestClassifier – for Pass/Fail prediction
- RandomForestRegressor – for grade prediction

### Key Learnings
- Study time, failures, and family support impact performance
- Classification model can help educators identify at-risk students
